Excel add-in

Excel taskpane sideload manifest · Excel taskpane

After sideloading the manifest inside Excel, use the taskpane to import source catalog worksheets, reference priors, lookup formulas and—if separately entitled—actual funding regressions and observed factor history. Installation in a real Excel client has not yet been independently accepted.

Connecting MotherDuck

Set a dedicated read-only MOTHERDUCK_TOKEN and strong EVENTRISK_ANALYST_KEY in the Railway service's private Variables. The database token must not be pasted into the website. For row-level admin exploration also set EVENTRISK_DATA_ADMIN_KEY; data-use rights must be approved independently.

Authentication uses the X-Analyst-Key request header on protected endpoints. A successful coverage response, not a public page loading, proves the live warehouse connection.

No claim: original publisher first-release times, event surprises, event-specific causal returns, licensed quotes or globally approved investment betas.
