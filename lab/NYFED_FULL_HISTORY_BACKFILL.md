# NY Fed SOFR and EFFR — full reference-rate history

The original `lab/phase1_nyfed_funding_rates.py` producer used the last 250 records for each original issuer series. That is only about one year of effective rates and unnecessarily truncates official historic data. Version `phase1-nyfed-overnight-rates-v1.1.0` instead calls the New York Fed's supported **historical search endpoint** `https://markets.newyorkfed.org/api/rates/secured/sofr/search.json` and `.../unsecured/effr/search.json`, with query `startDate=2018-04-02` and `endDate=<current UTC calendar date>`. Official documentation: https://markets.newyorkfed.org/static/docs/markets-api.html . Uses no FRED credentials, no third-party mirror, and no invented macro surprise data.

The producer fails closed on mismatched rate types, duplicate or future effective dates, implausible native annualized percent levels, malformed responses, fewer than 1,500 expected effective-date observations, oldest source observation after December 2018, or incomplete modern history. It preserves the full official JSON response **SHA-256**, retrieval time, revision indicator and source-URL bounds in the existing append-only source/observation tables. Versioned retrieval SHA hashes are raw response snapshots, **not** issuer-signed original historical revision versions. A series' daily effective date is not its exact first-publication timestamp.

The build checks source version deduplication and appends a fresh build's derived *rate-level changes* in basis points, using the official percentRate with 100 × consecutive change. These changes are NOT SOFR returns, funding policy surprises, or identified Fed policy shocks. Old last-250 source archives are preserved rather than deleted. The source data remain `research_only=TRUE`, with all independent original publisher-time, rights, surprise and institutional beta flags FALSE. New observations do not make ALFRED source vintages, historical announcement release clocks or vendor redistribution rights available.

Once deployed, run the pinned MotherDuck Flight with `LAB_RESEARCH_SCOPE=internal-only` and `LAB_PIPELINE_COMMIT`. Verify both source series extend to their official historical start dates and check new record counts, sampled level units, source metadata, and a repeat run for idempotent append-only versioning. Refresh the 16-family source inventory only after ingestion, then rerun the five-stage source-QA acceptance report. Institutional release cannot advance without independently documented clocks and licensed use. **Do not claim any current FRED key or FRED data load**: that source remains separately blocked on registered API credentials.
