    Functions and examples
    =ER.PROB("prop:venue:id")
    Latest event probability; q: IDs use their current headline.
    =ER.FIELD(A2,"volume")
    24-hour market volume; a mkt: ID selects a single venue.
    =ER.HISTORY(A2,B2,C2)
    Restated historical probability series; spills into adjacent cells.
    =ER.ASKNOWN(A2,B2)
    Probability with both as_of and known_as_of set to B2.
    =ER.EVENT(A2,"title")
    Event title or other supported metadata field.
    =ER.SEARCH("Taiwan")
    Event-contract IDs, names and current probabilities.
    =ER.UPDATED(A2)
    Latest source observation time; format the result as a date/time.

    Other helpers remain: ER.CHANGE, ER.NAME, ER.QUESTIONS, ER.RUNGS, ER.PROPOSITIONS, ER.EXPOSURES. All events here use prop: IDs; q: IDs group those contracts. Historic series use restated mappings, whereas ER.ASKNOWN is point-in-time. Venue market observations use mkt: IDs.
