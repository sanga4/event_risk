        Seven core Excel functions

        =ER.PROB(id)
        Latest event probability (0–1).
        =ER.FIELD(id,"volume")
        Latest market field; volume means trailing 24-hour volume.
        =ER.HISTORY(id,start,end)
        Historical probability table; spills into nearby cells.
        =ER.ASKNOWN(id,date)
        Probability as known at that date, using point-in-time information.
        =ER.EVENT(id,"title")
        Event or question title.
        =ER.SEARCH("Taiwan")
        Search matching questions and their headline event IDs.
        =ER.UPDATED(id)
        Last underlying price observation. Format the result as a date/time.
        More functions (unchanged)
        =ER.PROB(id, [as_of], [known_as_of])
        Probability, 0–1. A question id gives its headline (most-traded live) rung.
        =ER.CHANGE(id, [as_of], [known_as_of])
        24h change in probability.
        =ER.NAME(id)
        The question asked.
        =ER.QUESTIONS([query], [limit], [sort], [entity])
        Table of questions, biggest movers first.
        =ER.RUNGS(question_id, [as_of], [known_as_of])
        A question's ladder: every deadline / threshold.
        =ER.PROPOSITIONS([query], [limit], [sort], [entity])
        Table of single rungs, biggest movers first.
        =ER.EXPOSURES(ticker, [limit], [min_score], [as_of], [sort])
        Questions a security is exposed to, with signed impact.
        =ER.HISTORY(id, [start], [end], [interval])
        Probability over time (daily by default).
        =ER.SCAN(holdings, [limit], [move_threshold])
        Live portfolio scan over a ticker/weight range.

        A question's headline rung can change as trading moves; use a rung id from RUNGS to pin one deadline. Set known_as_of = as_of for a point-in-time, backtest-safe value. Exposure scores rank relevance; they are not betas.
